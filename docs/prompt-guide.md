# 프롬프트 구체화 가이드

프로젝트 진행 시 아래 템플릿으로 요청하면 결과 품질이 높아집니다.

## 1) 기능 구현 요청 템플릿

```text
[목표]
- 구현할 기능:
- 완료 기준:

[입력/출력]
- 입력 데이터 형태:
- 출력 데이터 형태:

[제약 사항]
- 사용 라이브러리:
- 성능/안전 제약:

[검증]
- 테스트 케이스:
- 실행 명령:
```

## 2) 전략 설계 요청 템플릿

```text
[전략명]

[아이디어]
- 어떤 시장 상황에서 수익을 기대하는지

[진입 조건]
- 지표/가격 조건

[청산 조건]
- 익절/손절/시간 기반 청산

[리스크 규칙]
- 최대 보유 종목 수
- 1회 주문 금액 제한

[백테스트 기준]
- 기간/종목/수수료/슬리피지
```

## 3) 디버깅 요청 템플릿

```text
[문제 현상]
- 발생 시점:
- 에러 로그:

[기대 동작]

[재현 방법]

[수정 범위]
- 파일:
- 영향 기능:
```
