# 프롬프트 구체화 가이드

## 1) 종목 선정 로직 변경 요청 템플릿

```text
[목표]
- 어떤 시장(코스피/코스닥/ETF)에서 무엇을 찾을지

[선정 기준]
- 모멘텀/밸류/퀄리티/변동성 중 어떤 팩터를 쓸지
- 최소 거래대금/시가총액 필터

[출력]
- 상위 N개 종목 코드 + 점수 + 선정 사유

[검증]
- 샘플 데이터로 랭킹 기대값
```

## 2) 퀀트 스윙 전략 구현 요청 템플릿

```text
[타임프레임]
- 일봉 / 4시간봉 등

[진입 규칙]
- 예: MA20 > MA60 and price > MA20

[청산 규칙]
- 손절 %, 익절 %, 추세 이탈 조건

[포지션 규칙]
- 최대 보유 종목 수
- 종목당 최대 비중

[테스트]
- 매수/매도/홀드 각각의 재현 케이스
```

## 3) API 연동 요청 템플릿

```text
[대상 API]
- 예: 일봉 조회, 주문, 잔고

[입력]
- 계좌/종목/기간

[변환]
- KIS 응답 -> 내부 모델(DailyBar 등) 매핑 규칙

[오류 처리]
- 재시도/토큰만료/시장휴장 처리
```
